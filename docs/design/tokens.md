# Дизайн-токены и общие компоненты

Реализация требований ТЗ, п. 6.1: академический стиль, светлая схема, тёмно-синие заголовки, светло-голубые информационные блоки, сдержанные цветовые индикаторы, карточная структура, единообразные кнопки и поля, адаптивная сетка. Цвет никогда не является единственным носителем статуса.

Источники истины:

- `apps/web/src/theme/tokens.css` — CSS-переменные `--iot-*` и базовые стили;
- `apps/web/src/theme/preset.ts` — пресет PrimeVue (Aura с тёмно-синей основной палитрой), см. ADR-008.

### Тона статусов

Используются компонентом `StatusBadge`. Каждый тон имеет иконку по умолчанию, текст статуса обязателен.

| Тон       | Фон / текст           | Иконка                    | Примеры статусов                                                          |
| --------- | --------------------- | ------------------------- | ------------------------------------------------------------------------- |
| `neutral` | `#eef1f5` / `#374151` | `pi-circle`               | Черновик, Не начат, Архивирована                                          |
| `info`    | `#e8f1fb` / `#163259` | `pi-info-circle`          | Активна, В работе, На проверке                                            |
| `success` | `#e6f4ea` / `#1d5e36` | `pi-check-circle`         | Завершена, Принято, Контрольная точка пройдена                            |
| `warning` | `#fdf2d8` / `#744600` | `pi-exclamation-triangle` | Требует корректировки, На доработке, Требуется дополнительная диагностика |
| `danger`  | `#fbe8e8` / `#8f1d1d` | `pi-times-circle`         | Просрочено, Контрольная точка пропущена                                   |

### Серии графиков

Используются графиками Chart.js (vue-chartjs), впервые — графиком динамики замеров во вкладке «Диагностика» профиля студента (этап 08). Компонент читает значения токенов через `getComputedStyle`, поэтому в коде графиков нет «сырых» цветов. Контраст каждого цвета с белым фоном — не ниже 3:1 (графические элементы). Серии различаются не только цветом, но и формой точек (круг, квадрат, треугольник, ромб, крест, звезда), а значения графика всегда дублируются таблицей (п. 6.1).

| Токен           | Значение  |
| --------------- | --------- |
| `--iot-chart-1` | `#1c3f70` |
| `--iot-chart-2` | `#0f766e` |
| `--iot-chart-3` | `#b45309` |
| `--iot-chart-4` | `#7e22ce` |
| `--iot-chart-5` | `#be123c` |
| `--iot-chart-6` | `#4d7c0f` |

Соответствие конкретных статусов тонам закрепляется на этапах, где появляются статусы (подписи статусов — `*_LABELS` в `packages/shared/src/enums.ts`).

## Типографика

- Шрифт: системный стек `system-ui, -apple-system, 'Segoe UI', Roboto, 'Noto Sans', …` — без загрузки шрифтов из интернета (работа в локальной сети колледжа). Все шрифты стека поддерживают кириллицу.
- Базовый размер — 15 px, межстрочный интервал — 1,5.
- h1 — 1,5 rem, h2 — 1,25 rem, цвет заголовков — `--iot-color-heading`.

## Адаптивность

| Ширина    | Поведение                                                                                                                                             |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| ≥ 1024 px | Постоянное левое меню, выбор группы и дисциплины в одной строке с шапкой                                                                              |
| < 1024 px | Меню преподавателя — выдвижная панель (кнопка «Открыть меню»); выбор группы и дисциплины — второй строкой шапки; у студента — нижняя панель навигации |
| < 600 px  | Уменьшенные поля страницы (16 px), скрыты подзаголовки шапки                                                                                          |
| 360 px    | Минимальная поддерживаемая ширина (NFR-004): горизонтальной прокрутки нет, проверяется Playwright                                                     |

## Доступность

- Переход «Перейти к содержимому» в начале каждой оболочки.
- Видимый контур фокуса `:focus-visible`.
- Иконки декоративны (`aria-hidden`), смысл всегда передаётся текстом.
- У кнопок-иконок есть `aria-label` («Открыть меню», «Уведомления»).
- Встроенные тексты PrimeVue локализованы на русский (`apps/web/src/plugins/primevue.ts`).
