# Макеты ключевых экранов

Текстовые макеты (wireframes) экранов из ТЗ, п. 6.2–6.5, и конструкторов (п. 4.4, 4.6). Они фиксируют состав и расположение блоков; оформление задаётся дизайн-токенами (`docs/design/tokens.md`), структура меню — картой навигации (`docs/design/navigation.md`).

Условные обозначения: `[Кнопка]`, `[▾ Выбор]`, `(●) статус` — бейдж статуса (цвет + иконка + текст), `▓▓▓░░ 60 %` — прогресс-бар, `«Нет данных»` — пустое состояние вместо нуля (FR-005). Все данные на макетах условные.

Общие правила для всех экранов:

- при отсутствии данных показывается пояснение (`EmptyState`), а не нули и не пустые графики;
- при ошибке загрузки — понятное сообщение и кнопка «Повторить» (`ErrorState`, NFR-005);
- статус никогда не передаётся только цветом;
- на ширине 360 px блоки выстраиваются в одну колонку, таблицы превращаются в списки карточек, горизонтальной прокрутки страницы нет.

│ ИОТ — цифровое             │

## 8. Администрирование и настройки (этап 03)

```
┌ Администрирование ─────────────────────────────────────────────┐
│ [Пользователи] [Роли и разрешения] [Журнал аудита]              │
│ 🔍 [ФИО, логин, e-mail]  [Все роли ▾] [Все состояния ▾] [+ Добавить сотрудника] │
│ ФИО / логин            Роли           Состояние        Последний вход │
│ Иванова А. С. a.ivanova Преподаватель ✔ Активна       16.10.2026 09:12 │
│ Петров И. И.  i.petrov  Исследователь ✖ Заблокирована —               │
└────────────────────────────────────────────────────────────────┘
```

- Карточка пользователя (диалог): ФИО и e-mail, роли (флажки), «Заблокировать» / «Разблокировать», «Сбросить пароль», индивидуальные разрешения с основанием и сроком. Блокировка и отзыв разрешения требуют причины. Временный пароль показывается один раз.
- Для собственной учётной записи действия недоступны с пояснением; для учётной записи студента — только блокировка и сброс пароля.
- «Роли и разрешения» — карточки ролей со списком разрешений, конфиденциальные отмечены значком «Конфиденциально».
- «Журнал аудита» — таблица: дата и время, действие, объект, автор, причина; строка раскрывается и показывает значения «до» и «после».
- «Настройки» — карточка «Вход в систему»: числовые поля с единицами, пояснением и допустимым диапазоном, кнопка «Сохранить».
- На 360 px таблицы прокручиваются внутри своего блока, фильтры переносятся на отдельные строки, диалоги занимают всю ширину экрана.

## 9. Смена пароля (этап 03)

Карточка по центру, как у страницы входа: текущий пароль, новый пароль, повтор нового, подсказка с требованиями к паролю, кнопка «Сменить пароль». После входа с временным паролем сверху — пояснение «Вы вошли с временным паролем…», а другие разделы недоступны до смены.
