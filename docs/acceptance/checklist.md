# Чек-лист приёмочного тестирования (п. 11.2 ТЗ)

Чек-лист для приёмочной комиссии. Для каждого критерия AT-01…AT-14 указано, что проверяется, как это сделать вручную на приёмочном стенде и какой автотест подтверждает критерий. Отметку о приёмке ставит комиссия.

## Подготовка стенда

Требуется Docker, Node.js 24 и pnpm (см. `README.md`), файл `.env.test` (копия `.env.example`).

```sh
pnpm install
pnpm db:up
pnpm acceptance:stand
```

Команда очищает отдельную базу `iot_acceptance`, заполняет её данными приёмки и запускает систему по адресу http://localhost:5273. Логины и пароли записываются в `apps/web/e2e/acceptance/stand.local.json`. Состав данных стенда описан в [docs/testing/scenarios/README.md](../testing/scenarios/README.md#приёмочный-стенд).

Автоматический прогон критериев AT-01…AT-12 на новом стенде:

```sh
pnpm test:acceptance
```

Отчёт прогона открывается командой `pnpm --filter @iot/web exec playwright show-report playwright-report/acceptance`.
