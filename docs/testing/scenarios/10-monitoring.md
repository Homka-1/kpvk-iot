# 10. Мониторинг и корректировка ИОТ

Требования: FR-043, FR-044, FR-056–FR-062, п. 4.8, UC-05, AT-08, AT-09.

| №     | Сценарий                         | Шаги                                                                                                                                   | Ожидаемый результат                                                                                                                      | Требования            | Автотест                                                      |
| ----- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------- | ------------------------------------------------------------- |
| 10.1  | Показатели мониторинга           | `teacher`: «Мониторинг», карточка студента 3 «ПО-21»                                                                                   | «выполнено 0 из 3», прогресс 0 %, «Нет данных: оценок нет»                                                                               | FR-056, п. 4.8        | приёмка: at-08-09-monitoring; api: monitoring                 |
| 10.2  | Изменение прогресса              | Студент 3 сдаёт задание, преподаватель принимает; обновить «Мониторинг»                                                                | «выполнено 1 из 3», прогресс больше 0, средний балл «100 % (оценок: 1)»                                                                  | AT-08, FR-042         | приёмка: at-08-09-monitoring; api: monitoring                 |
| 10.3  | Фильтры                          | Фильтры по группе, дисциплине, студенту, периоду                                                                                       | Список и показатели пересчитываются; только своя область                                                                                 | FR-057, FR-002        | api: monitoring; ui: monitoring                               |
| 10.4  | Предупреждения                   | Пропустить срок задания и контрольной точки                                                                                            | Предупреждения о просрочке и пропущенной точке; преподавателю уведомление один раз                                                       | FR-058                | api: monitoring; ui: monitoring                               |
| 10.5  | Графики динамики                 | Детали мониторинга студента                                                                                                            | Графики выполнения и оценок; диагностика — отдельным блоком                                                                              | FR-059, FR-062        | ui: monitoring                                                |
| 10.6  | Активность и мотивация раздельно | Студент не входит в систему                                                                                                            | Отсутствие входа не меняет показатели диагностики                                                                                        | FR-062                | api: monitoring                                               |
| 10.7  | Доп. сопровождение               | Отметить «нужно дополнительное сопровождение»                                                                                          | Отметка видна в мониторинге и в фильтре студентов                                                                                        | FR-060                | api: monitoring                                               |
| 10.8  | Корректировка ИОТ (UC-05)        | Карточка студента 4 → «Подробнее и корректировка» → «Корректировать ИОТ» → изменить способы сопровождения → «Подтвердить новую версию» | Без причины — ошибка «Укажите причину корректировки»; с причиной — «Утверждена версия 2: прежняя версия сохранена»; студенту уведомление | AT-09, FR-043, FR-061 | приёмка: at-08-09-monitoring; ui: monitoring; api: monitoring |
| 10.9  | История версий                   | «История версий» → «Открыть версию 1»                                                                                                  | Версия 1 открывается без изменений; у версии 2 — причина и список изменений                                                              | AT-09, FR-043         | приёмка: at-08-09-monitoring; api: monitoring, database       |
| 10.10 | Завершение маршрута              | Завершить ИОТ с итоговой оценкой, затем архивировать                                                                                   | Статус «Завершена», оценка видна студенту; затем «Архивирована»                                                                          | FR-044                | api: monitoring                                               |
