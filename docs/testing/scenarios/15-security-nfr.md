# 15. Безопасность и нефункциональные требования

Требования: п. 8.3, NFR-001–NFR-007, NFR-010, AT-12. Подробные результаты — [security.md](../security.md) и [load.md](../load.md).

| №     | Сценарий                       | Шаги                                                                                         | Ожидаемый результат                                                                                       | Требования       | Автотест                                           |
| ----- | ------------------------------ | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------- |
| 15.1  | Студент и чужие данные         | Студент `p-1005` открывает страницы сотрудников и чужие записи по прямым ссылкам и через API | Переход на главную кабинета; API отвечает 403/404; свои данные доступны                                   | AT-12            | приёмка: at-12-student-access; api: idor           |
| 15.2  | Права каждого маршрута         | Автоматический обход всех маршрутов API                                                      | Без входа — только вход, обновление сессии, выход, health; каждый маршрут требует разрешения              | п. 8.3, FR-002   | api: route-guards                                  |
| 15.3  | Подмена идентификаторов (IDOR) | Чужой преподаватель и студент обращаются ко всем маршрутам с идентификаторами                | Строго 403/404 для всех методов                                                                           | AT-12            | api: idor                                          |
| 15.4  | Заголовки безопасности         | Любой ответ API                                                                              | CSP, X-Frame-Options, Referrer-Policy, HSTS, `Cache-Control: no-store`, нет X-Powered-By                  | п. 8.3           | api: security                                      |
| 15.5  | Понятные ошибки                | Большое тело, некорректный JSON, неизвестный адрес, ошибка сервера                           | Сообщения на русском без технических подробностей и ПДн                                                   | NFR-005          | api: security, logging; ui: navigation             |
| 15.6  | Повторная отправка форм        | Повторить отправку формы с тем же ключом                                                     | Дубль не создаётся; тот же ключ с другими данными — 409                                                   | NFR-006          | api: students, security и др.                      |
| 15.7  | Нагрузка                       | k6: 50 одновременных пользователей 3 минуты                                                  | p95 каждого основного экрана ≤ 3 с, ошибок < 1 %                                                          | NFR-001, NFR-002 | test/load (k6), см. load.md                        |
| 15.8  | Браузеры                       | Набор Playwright в Chromium, Firefox, WebKit                                                 | Все сценарии проходят                                                                                     | NFR-003          | ui: все файлы (`pnpm test:e2e`, `test:e2e:webkit`) |
| 15.9  | Экран 360 px                   | Основные экраны в проекте `mobile-360` и в приёмочном AT-06                                  | Нет горизонтальной прокрутки, навигация студента в нижней панели                                          | NFR-004          | ui: mobile-360; приёмка: at-06-student-trajectory  |
| 15.10 | Миграции                       | Применить миграции к пустой базе и к базе предыдущей версии                                  | Все таблицы п. 7 созданы, данные сохранены                                                                | NFR-007          | api: database                                      |
| 15.11 | Разделение окружений           | Сравнить базы и каталоги файлов разработки, автотестов, приёмки, нагрузки                    | У каждого окружения своя база (`iot_dev`, `iot_test`, `iot_acceptance`, `iot_load`) и свой каталог файлов | NFR-010          | стенд приёмки, `.env.example`                      |
| 15.12 | Зависимости                    | `pnpm audit:deps`                                                                            | Нет уязвимостей уровня high и critical                                                                    | п. 8.3           | `pnpm audit:deps`                                  |
