# 11. Обратная связь и уведомления

Требования: FR-008, FR-016, FR-063–FR-068, п. 4.9.

| №    | Сценарий                          | Шаги                                                                                                      | Ожидаемый результат                                                               | Требования             | Автотест                      |
| ---- | --------------------------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ---------------------- | ----------------------------- |
| 11.1 | Вопрос по заданию                 | Студент: «Обратная связь» → вопрос с привязкой к заданию; преподаватель отвечает и отмечает «рассмотрено» | Сообщение привязано к заданию, этапу и студенту; обе стороны получают уведомления | FR-063, FR-064, FR-065 | api: feedback; ui: feedback   |
| 11.2 | Бейдж уведомлений                 | Получить новое сообщение                                                                                  | В шапке бейдж с числом непрочитанных; после прочтения — сбрасывается              | FR-065                 | api: feedback; ui: navigation |
| 11.3 | Сообщение о затруднении           | Студент сообщает о затруднении                                                                            | Студент попадает в фильтр «Затруднения» до рассмотрения                           | FR-008                 | api: feedback                 |
| 11.4 | Консультации                      | Студент запрашивает консультацию; преподаватель назначает, проводит, фиксирует итог                       | История консультаций в профиле и в кабинете                                       | FR-067                 | api: feedback; ui: feedback   |
| 11.5 | Рефлексия после контрольной точки | Отметить контрольную точку пройденной; студент заполняет рефлексию дважды                                 | Одна рефлексия на точку, без дублей; видна преподавателю                          | FR-066, NFR-006        | api: feedback; ui: feedback   |
| 11.6 | Запрос самооценки                 | Преподаватель запрашивает самооценку; студент отвечает                                                    | Ответ закрывает запрос                                                            | FR-066                 | api: feedback                 |
| 11.7 | Внутренние заметки                | Преподаватель оставляет внутреннюю заметку и видимый студенту комментарий                                 | Студент видит только комментарий; заметка не приходит ни в одном ответе API       | FR-068, FR-016, AT-12  | api: feedback                 |
