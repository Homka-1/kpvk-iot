# 2. Группы, дисциплины, студенты

Требования: FR-002, FR-005–FR-011, MVP-2, MVP-3, AT-01, AT-12.

| №   | Сценарий                             | Шаги                                                                               | Ожидаемый результат                                                                                               | Требования             | Автотест                                     |
| --- | ------------------------------------ | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------- | -------------------------------------------- |
| 2.1 | Справочники администратора           | Войти `admin`: «Дисциплины» → создать дисциплину и группу, закрепить преподавателя | Повтор названия — понятная ошибка; снятие закрепления сохраняет историю; группу со студентами архивировать нельзя | п. 2.1                 | api: students; ui: students                  |
| 2.2 | Две исследовательские группы         | Войти `teacher`, «Студенты», выбрать в шапке «ПО-21», затем «ПО-22»                | «Найдено студентов: 20» в каждой группе                                                                           | AT-01                  | приёмка: at-01-research-groups               |
| 2.3 | Ручное добавление студента           | «Студенты» → «Добавить студента», заполнить ФИО и группу, отправить форму дважды   | Создана карточка и учётная запись с временным паролем (показан один раз); повтор не создаёт дубль                 | FR-006, NFR-006        | api: students                                |
| 2.4 | Импорт CSV/XLSX                      | Загрузить файл с корректными и ошибочными строками; затем битый файл               | Предпросмотр с ошибками по строкам; импорт корректных строк; битый файл — понятная ошибка                         | FR-006                 | api: students; ui: students                  |
| 2.5 | Поиск и фильтры                      | Поиск по фамилии и коду; фильтры по профилю, статусу ИОТ, затруднениям             | Список фильтруется; при пустых данных — пояснение, а не нули                                                      | FR-005, FR-007, FR-008 | api: students; ui: students                  |
| 2.6 | Перевод в другую группу              | Карточка студента → «Перевести», указать группу и причину                          | Студент в новой группе; история групп сохранена                                                                   | FR-010                 | api: students                                |
| 2.7 | Архивирование                        | Архивировать студента с причиной, затем вернуть                                    | Студент скрыт из списка, вход закрыт, данные сохранены; после возврата — снова доступен                           | FR-011                 | api: students                                |
| 2.8 | Область данных преподавателя         | Войти преподавателем без закреплений                                               | Пояснение «нет закреплённых групп»; чужие студенты не видны (404)                                                 | FR-002                 | api: students, admin; ui: students           |
| 2.9 | Список студентов недоступен студенту | Войти студентом и открыть `/students`                                              | Переход на главную кабинета; API списка — 403                                                                     | AT-12                  | api: students; приёмка: at-12-student-access |
