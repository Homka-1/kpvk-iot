# 4. Конструктор диагностических методик

Требования: FR-017, FR-020, FR-021, FR-026, п. 4.4, п. 11.3, огр. 1.

| №   | Сценарий                         | Шаги                                                                                               | Ожидаемый результат                                                                       | Требования              | Автотест                             |
| --- | -------------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------- | ------------------------------------ |
| 4.1 | Создание методики                | «Диагностика» → «Создать методику»: паспорт, вопросы пяти типов, варианты, шкала с обратным ключом | Черновик версии 1; ошибки ключей показаны по полям; повтор формы не создаёт дубль         | FR-017, FR-021, NFR-006 | api: questionnaires; ui: diagnostics |
| 4.2 | Правила интерпретации            | Задать диапазоны баллов и уровни для шкалы                                                         | Пересекающиеся и неполные диапазоны не дают опубликовать методику                         | FR-021                  | api: questionnaires                  |
| 4.3 | Публикация                       | Опубликовать версию, попробовать изменить её                                                       | Опубликованная версия неизменяема (защищена и в базе)                                     | FR-026                  | api: questionnaires, database        |
| 4.4 | Новая версия при изменении ключа | Создать новую версию, изменить ключ, опубликовать                                                  | Прежняя версия и её результаты не изменились; новые прохождения считаются по новой версии | FR-026, п. 7 ТЗ         | api: questionnaires                  |
| 4.5 | Контрольные примеры              | Прогнать контрольные примеры `apps/api/test/fixtures/diagnostics/<методика>/<версия>/*.json`       | Расчёт совпадает с ожидаемыми баллами и уровнями                                          | п. 11.3, FR-020         | unit: control-examples (apps/api)    |
| 4.6 | Копирование и архив              | Скопировать демо-методику, архивировать с причиной, вернуть                                        | Копия демо остаётся «ДЕМО»; архивную нельзя изменить; действия в аудите                   | FR-017, огр. 1          | api: questionnaires                  |
| 4.7 | Направления диагностики          | Вкладка «Направления»                                                                              | Пять направлений п. 4.4, можно добавить своё                                              | п. 4.4                  | api: questionnaires; ui: diagnostics |
| 4.8 | Доступ к конструктору            | Войти администратором, исследователем, студентом                                                   | Раздел и API методик недоступны (403)                                                     | п. 2.1                  | api: questionnaires; ui: diagnostics |
