| №   | Сценарий                      | Шаги                                                                                           | Ожидаемый результат                                                                       | Требования              | Автотест                            |

| 7.1 | Материал: файл, ссылка, текст | «Библиотека материалов» → добавить три вида материалов по дисциплине и теме                    | Материалы сохранены; ссылка открывается в новой вкладке без доступа к окну приложения     | п. 4.7                  | api: library; ui: library           |
