# 3. Профиль студента и педагогические наблюдения

Требования: FR-009, FR-012, FR-014, FR-016, п. 2.3, п. 4.3.

| №   | Сценарий                  | Шаги                                                                                      | Ожидаемый результат                                                                                     | Требования      | Автотест                          |
| --- | ------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | --------------- | --------------------------------- |
| 3.1 | Профиль из списка         | «Студенты» → карточка студента                                                            | Профиль с семью вкладками; «Общие сведения»: группа, дисциплины, преподаватели; пропуски — «Нет данных» | FR-009, FR-012  | api: profile; ui: profile         |
| 3.2 | Педагогическое наблюдение | Вкладка «Общие сведения» → «Добавить наблюдение», дважды отправить форму                  | Наблюдение с датой и автором; повтор не создаёт дубль                                                   | FR-014, NFR-006 | api: profile; ui: profile         |
| 3.3 | Служебные заметки         | Добавить служебное наблюдение и открытое студенту; войти студентом, открыть «Мой профиль» | Студент видит только открытое наблюдение; служебное не приходит ни в одном ответе API                   | FR-016          | api: profile, feedback            |
| 3.4 | Интересы студента         | Студент в «Мой профиль» указывает интересы; преподаватель открывает профиль               | Интересы видны преподавателю                                                                            | п. 2.3          | api: profile; ui: profile         |
| 3.5 | История                   | Вкладка «История»                                                                         | Значимые события (диагностика, профиль, ИОТ) с датой и автором                                          | FR-012          | api: profile, diagnostic-sessions |
| 3.6 | Чужой профиль             | Преподаватель другой группы, исследователь и администратор открывают профиль              | Чужой студент — 404; исследователю, администратору и студенту — 403                                     | FR-002, AT-12   | api: profile, idor                |
