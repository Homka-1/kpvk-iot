## Найденные при прогоне проблемы

| №   | Проблема                                                                                                                                                                                                         | Решение                                                                                                    |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 1   | На экране 360 px dev-сервер Vite перезагружал страницу посреди сценария, когда впервые встречал новую зависимость, и обрывал запрос обновления сессии                                                            | Не ошибка продукта: стенд приёмки работает на production-сборке интерфейса (`vite build` + `vite preview`) |
| 2   | В журнале API предупреждение pg: «Calling client.query() when the client is already executing a query is deprecated». Источник — параллельные запросы в транзакции в рантайме Prisma (@prisma/adapter-pg 7.10.1) | Сейчас не влияет на работу. При обновлении pg до версии 9 проверить совместимость адаптера Prisma          |

Ошибок в функциональности по критериям AT-01…AT-12 не найдено.

## Как повторить

```sh
pnpm install
pnpm db:up
pnpm lint && pnpm typecheck && pnpm test && pnpm test:e2e && pnpm test:acceptance
```

Порядок нагрузочного теста — [load.md](load.md); на приёмочном стенде — раздел «Повтор на приёмочном стенде».
